# GrandThrowAuto 
Finished version of [GrandThrowAuto](https://github.com/Lamparter/GrandThrowAuto), a game made at Campfire Flagship by [Lamparter](https://github.com/Lamparter), [Starianne](https://github.com/Starianne) and me.

It has been converted to JS and HTML Canvas for web support.

## How to play

SPACE to drop bricks, hold space to drop a big brick.

- Drop bricks on cars to gain points, green cars give more points than red ones.
- Police cars (blue ones) must be destroyed with a heavier brick - hitting them with a normal brick loses points.
- Any cars which leave the screen (except police cars) lose points.
- You can only drop bricks when you have sufficient stamina - big bricks require more stamina.
- Running out of points loses the game.
Survive for as long as possible!

Try it out [here](https://stalhein.github.io/grand_throw_auto_v2/).
